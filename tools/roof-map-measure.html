How to measure

  1. Type the street address and pick a result (biased to SEQ).
  2. Zoom until you can see the roof sheets clearly.
  3. Click the polygon icon, then click corners of the roof. Finish by clicking the first point again.
  4. Add more polygons for detached garages or separate wings — areas add up.
  5. Optional: set pitch (e.g. 22.5°) so surface m² is used for costing.
  6. Send m² to the cost estimator.

Imagery: Esri / Maxar satellite tiles (similar quality to Google satellite for planning). Address search via Photon/OpenStreetMap data.
